# Suwarna Rota v4.0 Professional Edition

Data range: **1 May 2026 to 7 March 2027** (311 consecutive dates).

## Visible v4 improvements
- New Home dashboard with next-shift countdown and upcoming shifts
- Search, month selector and Today button in one line in Weekly view
- Cleaner Weekly cards and sticky week headers
- Calendar with clearer names, school-holiday shading and tap-for-details
- Private notes saved on the device for individual dates
- Summary month selector, shift-mix bars and editable annual-leave allowance
- Correct AL, SL/PSL, NICU long-day and 2027 weekday handling
- Installable offline PWA with update-safe v4 cache

## Publish on GitHub Pages
Upload every file in this folder to the repository root. In GitHub open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.

## Future rota updates
Replace `rota.csv` using columns `date,shift`. Blank shifts are treated as Off.
